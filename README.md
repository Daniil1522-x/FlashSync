# ⚡ FlashSync Pro

Профессиональный синхронизатор файлов между флешкой и компьютером.
Работает в терминале через красивый TUI-интерфейс (Textual).

---

## Что программа умеет

- Сравнивает содержимое двух папок (по SHA-256 или по размеру+дате)
- Показывает план изменений **до того** как что-то сделает
- Копирует новые и обновлённые файлы
- Перед заменой файла сохраняет старую версию в папку `.flashsync_backup_ДАТА`
- Защищает важные файлы от случайного изменения/удаления (по имени)
- Работает в режиме **Dry Run** — симуляция без реальных изменений
- Сохраняет отчёты в `~/.flashsync/reports/`

## Быстрый старт

### Установка зависимостей

```
pip install textual aiofiles tqdm
```

или через uv:

```
uv add textual aiofiles tqdm
```

### Запуск TUI (рекомендуется)

```
python main.py
```

### Запуск CLI-меню (без Textual)

```
python main.py --cli
```

### Команды из терминала напрямую

```
python main.py scan  -s E:\FLASH -d E:\Backup        # показать план
python main.py sync  -s E:\FLASH -d E:\Backup        # синхронизировать
python main.py sync  -s E:\FLASH -d E:\Backup --dry-run   # симуляция
python main.py audit -s E:\FLASH -d E:\Backup        # аудит хешей
python main.py stats E:\FLASH                        # статистика папки
```

## Сборка .exe (запуск без Python)

pip install pyinstaller

Запускать двойным кликом или из терминала:

```
flashsync.exe          # TUI
flashsync.exe --cli    # CLI меню
```

## Интерфейс TUI — объяснение кнопок

```
┌─────────────────────────────────────────────────────┐
│ [Сканировать] [Синхронизировать] [Dry Run] [Настройки]│
│ Источник │       ПЛАН ИЗМЕНЕНИЙ        │ Статистика  │
│ (дерево) │ + новый  ~ обновить  - бэкап│    + лог    │
│          │                             │             │
└──────────────────── статус ─────────────────────────┘
```

### Кнопки

| Кнопка | Горячая клавиша | Что делает |
|--------|-----------------|------------|
| **Сканировать** | Ctrl+S | Читает обе папки, строит список изменений. Ничего не меняет. |
| **Синхронизировать** | Ctrl+R | Выполняет план: копирует новые, обновляет изменённые, старые версии — в backup. |
| **Dry Run** | Ctrl+D | Показывает что **будет** сделано, но ничего не трогает. Безопасно. |
| **Обратить src<->dst** | — | Меняет местами источник и приёмник (синхронизация в обратную сторону). |
| **Настройки** | Ctrl+P | Изменить пути, включить/выключить хеш-сравнение и режим удаления. |
| **Выход** | Ctrl+Q | Закрыть программу. |

### Что означают символы в таблице плана

| Символ | Цвет | Действие |
|--------|------|----------|
| `+` | зелёный | Файл новый — будет скопирован в dst |
| `~` | жёлтый | Файл изменился — будет обновлён (старый → backup) |
| `-` | красный | Файл только в dst — будет перемещён в backup |
| `=` | серый | Файлы одинаковые — ничего не делать |
| `L` | голубой | Файл защищён — трогать нельзя |

### Что такое Dry Run?

**Dry Run** (сухой прогон) — режим симуляции. Программа показывает ЧТО она сделала бы, но на самом деле не копирует и не удаляет ничего. Используйте перед первой реальной синхронизацией чтобы убедиться что план правильный.

### Что такое palette (Ctrl+P в Textual)?

Встроенная функция Textual — командная палитра. Показывает список команд. В нашем приложении Ctrl+P переназначен на "Настройки", но Textual иногда показывает свою палитру. Можно игнорировать.

## Настройки профиля

Профиль хранится в файле `C:\Users\ИМЯ\.flashsync\config.json` (Windows) или `~/.flashsync/config.json` (Linux).

| Параметр | Описание |
|----------|----------|
| **Источник** | Путь к флешке или папке-источнику |
| **Приёмник** | Путь куда копировать |
| **SHA-256** | Сравнивать файлы по содержимому (медленнее, но точнее). Если выключено — сравнение по размеру и дате. |
| **Удалять из dst** | Если файл есть в dst но нет в src — переместить в backup |
| **Игнорировать скрытые** | Пропускать `.DS_Store`, `Thumbs.db` и т.п. |

## Защита файлов

Файлы с определёнными словами в имени автоматически защищены:

| Паттерн | Уровень | Поведение |
|---------|---------|-----------|
| `*important*` | DOUBLE | Требует 2 подтверждения для изменения |
| `*contract*`  | DOUBLE | Требует 2 подтверждения |
| `*personal*`  | DOUBLE | Требует 2 подтверждения |
| `*backup*`    | SINGLE | Требует 1 подтверждение |
| `*final*`     | SINGLE | Требует 1 подтверждение |

Правила можно редактировать в `C:\Users\ИМЯ\.flashsync\config.json` (Windows) или `~/.flashsync/config.json` (Linux).

## Backup

Программа **никогда не удаляет файлы безвозвратно**.
При обновлении или удалении файл сначала копируется в папку:

```
dst/.flashsync_backup_20250419_143022/
```

Папки backup не синхронизируются (начинаются с `.`).

## Где хранятся файлы программы

На **Windows**:
```
C:\Users\ВашеИмя\.flashsync\
    config.json      — профили синхронизации
    flashsync.log    — журнал работы
    reports\         — отчёты синхронизации
```

На **Linux/macOS**:
```
~/.flashsync/
    config.json
    flashsync.log
    reports/
```

Путь также отображается в правой панели интерфейса.
