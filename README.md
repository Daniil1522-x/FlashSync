# FlashSync Pro

TUI-синхронизатор файлов между флешкой и ПК на Python (Textual).

## Возможности

- Сканирование источника и приёмника с подсчётом изменений (новые, изменённые, удалённые файлы)
- Сравнение по размеру+дате или по SHA-256 хешу содержимого
- Безопасное удаление: файлы перемещаются в `.flashsync_backup_*`, а не удаляются навсегда
- Защита файлов по шаблонам имён (`*important*`, `*contract*` и т.д.) с одиночным/двойным подтверждением
- Ручное управление планом синхронизации (Файлы → выбрать файлы → задать действие)
- Ручные изменения переживают повторное сканирование (`PlanOverrides`)
- Запоминание последнего сканирования между запусками (`SessionManager`)
- Dry Run — симуляция без реальной записи на диск
- Отмена синхронизации в любой момент (кнопка "■ Стоп")
- Фильтры плана (новые / изменённые / в backup / защищённые)
- Профили синхронизации (несколько пар src↔dst)
- Перехват крашей с подробным traceback (`crash_reporter`)
- 84+ юнит и интеграционных тестов

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Тесты

```bash
pytest tests/test_core.py -v
```

## Структура проекта

```
FlashSync/
├── domain/models.py              Модели данных (FileInfo, SyncAction, SyncProfile...)
├── application/
│   ├── differ.py                 Построение плана синхронизации
│   ├── sync_engine.py            Исполнение плана (копирование, backup, удаление)
│   ├── plan_overrides.py         Ручные изменения, переживающие пересканирование
│   └── session.py                Сохранение/восстановление последнего скана
├── infrastructure/
│   ├── scanner.py                Сканирование директорий (генератор, error_cb)
│   ├── hasher.py                 SHA-256 хеширование и верификация
│   ├── storage.py                Профили, конфигурация, отчёты
│   ├── drives.py                 Обнаружение съёмных носителей
│   ├── copier.py                 Копирование (батчи + чанки для больших файлов)
│   └── crash_reporter.py         Перехват необработанных исключений
├── ui/tui/
│   ├── app.py                    Главный экран приложения
│   ├── file_manager.py           Экран ручного управления файлами
│   ├── folder_picker.py          Навигация по файловой системе
│   └── crash_screen.py           Просмотр crash-репортов
├── tests/test_core.py            Полный набор тестов
├── scripts/
│   ├── generate_test_data.py     Генерация тестовых данных
│   └── build_exe.py              Сборка standalone .exe (PyInstaller)
└── main.py                       Точка входа
```

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Ctrl+S | Сканировать |
| Ctrl+R | Синхронизировать |
| Ctrl+D | Dry Run |
| Ctrl+F | Управление файлами |
| Ctrl+P | Настройки |
| Ctrl+Q | Выход |

## Безопасность

DELETE_PERM (безвозвратное удаление) реализован в коде, но кнопка убрана из UI —
для синхронизатора флешка↔ПК риск случайной потери данных не оправдан. Все
удаления по умолчанию идут через backup-папку, либо через системную корзину
(`send2trash`), откуда файл можно восстановить.
